# TESS Trademark Search — OpenHospitalCost

**Why.** Per PROJECT_BRIEF.md Section 10, clear OpenHospitalCost in USPTO Classes 35, 42, and 44 before any commercial / branded launch. Domain registration does not require clearance, but going public with branded materials does.

**When.** Run this search in Phase A so the result is back well before Phase E (launch).

---

## Search protocol

Use TESS at https://tmsearch.uspto.gov/ (or the newer TM Search interface).

### Searches to run

For each class, run:

- Exact mark: `OpenHospitalCost`
- Stem variants: `Open Hospital Cost`, `OpenHospital`, `HospitalCost`
- Phonetic / visual variants: `OpnHospitalCost`, `OpenHospitalCosts`
- Live AND dead filter both — dead marks can reveal historical landmines.

### Classes

- **Class 35** — advertising, business services (covers ad-supported content sites).
- **Class 42** — software / SaaS / scientific services (covers the technical product).
- **Class 44** — medical services (covers anything implying we provide care; usually NO for us, but worth confirming we're not adjacent to a registered medical mark).
